# Contracts (Shared Interfaces)

This file documents every shared type and module interface. It is the reference for all team members.
See `src/types.ts` for the authoritative TypeScript definitions.

## Key Types

### ShipDesign
A player's ship configuration. Owned by **builder** (Owner 2). Contains `PartInstance[]`.

### ShipStats (computed)
Derived stats from a ShipDesign + Body. Computed by `computeShipStats()`. Owner 2.

### FlightResult
Output of a flight simulation. Owner 1 (sim).

### MissionResult
Combines FlightResult + ScavengeResult + wear data. Used by economy + report.

### SaveGame
Persistent player state. Managed by `save-load.ts`. Owner 3.

### MissionReport
Post-mission analysis. Generated by `generateReport()`. Owner 6.
